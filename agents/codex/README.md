# bs_score — Codex

Wrapper for **Codex**. Canonical skill + scorer: repository root of [alexhawat/bs_score](https://github.com/alexhawat/bs_score).

Install: point Codex at this folder or the repo-root `SKILL.md` / `AGENTS.md` snippet. Set `BS_SCORE_ROOT` to the clone and run `python3 "$BS_SCORE_ROOT/score.py" findings.json`.
