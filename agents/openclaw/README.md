# bs_score — OpenClaw

Wrapper for **OpenClaw**. Canonical skill + scorer: repository root of [alexhawat/bs_score](https://github.com/alexhawat/bs_score).

Install: drop this folder into the OpenClaw skills path. Instruction-only wrapper — run `score.py` from a clone (`BS_SCORE_ROOT`); do not vendor `.py` into OpenClaw packs.
