# bs-score — Cursor

Wrapper for **Cursor**. Canonical skill and scorer:
[alexhawat/bs-score](https://github.com/alexhawat/bs-score).

Skills folder: `~/.cursor/skills/bs-score` (personal) or `.cursor/skills/bs-score` (project). Cursor also reads `.agents/skills/` inside the repository.

```bash
git clone --depth 1 https://github.com/alexhawat/bs-score ~/.cursor/skills/bs-score
uv tool install git+https://github.com/alexhawat/bs-score   # the bs-score command
```

Scoring:

```bash
bs-score findings.json --repo-root .          # installed
uv run bs-score findings.json --repo-root .   # from a clone
```

Every install option: [repository README](https://github.com/alexhawat/bs-score#install).
