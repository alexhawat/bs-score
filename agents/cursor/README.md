# bs_score — Cursor

Wrapper for **Cursor**. Canonical skill + scorer: repository root of [alexhawat/bs_score](https://github.com/alexhawat/bs_score).

Install: add this folder under your Cursor skills/rules path, or `@` the root `SKILL.md` from a clone of this repo. Run `score.py` from `BS_SCORE_ROOT`.
