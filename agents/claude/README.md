# bs_score — Claude Code

Wrapper for **Claude Code**. Canonical skill + scorer: repository root of [alexhawat/bs_score](https://github.com/alexhawat/bs_score).

Install: copy or symlink this folder to `~/.claude/skills/bs_score` (or your project `.claude/skills/bs_score`). Keep a clone of the full repo so `score.py` is available via `BS_SCORE_ROOT`.
